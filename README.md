# Crowders Camps calendar: website copy

Upload this whole folder to a GitHub repository and turn on GitHub Pages for it. `index.html` is the calendar page and `assets/` holds the fonts and logo; neither changes day to day. `data.js` holds the events and is the only file the daily update replaces.
`embed.html` is the snippet to paste into the website, which keeps the frame the right height.

This copy is regenerated by `../build.py` from the CampWise data. Staff contacts, staff & operations items and all item notes are left out of it, because it is meant to be public.

Link settings (also work in the embed): `?camp=ridge` (or `smcc`, `springs`, comma-separated), `?view=list`, `?details=meal,act`.
Detail keys: arr (arrival & departure), meal, prog (program), act (activities), space (meeting spaces), lodge, rent (rentals), pkg (package).
